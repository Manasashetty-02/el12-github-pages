
# Frequently Asked Questions (FAQ)

## 1. What is GitHub Pages?

GitHub Pages is a service used to host static websites from a GitHub repository.

## 2. What is Markdown?

Markdown is a simple formatting language used to create documentation.

## 3. Is GitHub Pages free?

Yes, GitHub Pages supports free hosting for public repositories.
